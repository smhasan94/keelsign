# keelsign-ffi

C ABI static library (`libkeelsign.a`) and cbindgen header
(`include/keelsign.h`) for [`keelsign-verify`](../keelsign-verify), the `no_std`,
heap-free verifier of keelsign's post-quantum signed MCUboot images. It is the library
behind keelsign's MCUboot image-check hook (`boot_image_check_hook`,
[docs/mcuboot.md](../docs/mcuboot.md)).

Pre-release and not published: build it from the repository root.

```sh
cargo build -p keelsign-ffi --profile ffi --locked --target thumbv7em-none-eabihf [--features ed25519,ml-dsa]
```

The library is `target/<triple>/ffi/libkeelsign.a`. Default features verify LMS/HSS
images under `KEELSIGN_POLICY_PQ_ONLY`; `ed25519` adds the classical and hybrid policies,
`ml-dsa` adds ML-DSA-44/65.

```c
#include "keelsign.h"

keelsign_key_t key = { KEELSIGN_ALG_LMS_HSS, lms_public_key, sizeof lms_public_key };
keelsign_result_t result;
keelsign_status_t status =
    keelsign_verify(image, image_len, &key, 1, KEELSIGN_POLICY_PQ_ONLY, &result);
if (status != KEELSIGN_OK) { /* reject the image */ }
```

`keelsign_verify_cb` takes a `keelsign_reader_t { ctx, len, read }` instead of a pointer,
for images in flash that is not memory-mapped (MCUboot's `flash_area_read`).

The header is generated by cbindgen 0.29.4 and never edited by hand. The pointer and
length contract, every status code, the C harness and the size and symbol checks are in
[docs/ffi.md](../docs/ffi.md); sizes are in
[docs/benchmarks.md](../docs/benchmarks.md#c-static-library-sha-60).
